# Project Title: Call Center Performance Analytics Dashboard

**Overview:**

Developed an interactive, end-to-end performance dashboard in Microsoft Excel to track and analyze call center operations. 
This project transforms raw operational data into actionable business insights, enabling stakeholders to monitor key performance indicators (KPIs) and drive data-driven decision-making.

**Key Technical Skills Demonstrated:**

Data Cleaning & Management: Utilized Power Query to automate data extraction, transformation, and cleaning, ensuring a scalable and repeatable workflow.

Data Modeling: Implemented a relational data model (Power Pivot) to integrate multi-source datasets (calls and customer demographics), allowing for deeper cross-functional analysis.

Advanced DAX & Formulas: Created complex measures and calculated columns using DAX and advanced Excel functions (e.g., XLOOKUP, CALCULATE, IFERROR) to calculate metrics like call volume, customer satisfaction trends, and representative performance.

Interactive Visualization: Built a dynamic, user-friendly dashboard featuring Slicers, Timelines, and Pivot Charts that allow users to drill down into specific representatives, time periods, and customer demographics.

Conditional Formatting & UI/UX: Applied advanced formatting techniques and visual elements to enhance data readability and provide immediate visual cues for performance outliers.

**Business Impact:**

The dashboard provides a clear view of call center efficiency, helping management identify high-performing representatives, seasonal call volume peaks, and areas requiring additional training or support.
